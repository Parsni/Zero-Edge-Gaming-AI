SMALL ML BASELINE · CONTROLLED BYTE-FLIP TRIALS

Metadata cannot see a changed byte.

A tiny logistic-regression model trained on dimensions, duration, file size and bitrate was compared with the cryptographic audit. Each clean/tampered pair has identical metadata; the report shows the measured holdout result. This is not a deepfake detector.

THE RESEARCH DIRECTION

Edge capture → operator-marked event segment → signed input manifest → transformation receipt → later file-integrity audit for esports media. The activity ranker suggests a moment after the upload hash check; no semantic event detection is implemented. Device identity, frame-bound evidence, deployed AWS storage and a public ledger remain future work.

What this does not prove
The client key is not tied to a person or device. Input telemetry is client supplied. The server now recomputes signed chunk hashes against uploaded bytes, but their timing is not tied to decoded frames. No blockchain, zero-knowledge proof, serverless deployment, or human-authenticity detection is implemented.
